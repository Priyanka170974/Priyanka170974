## 🚀 FEATURED PROJECT — GITPULSE

### Repository Intelligence Dashboard

[![GitPulse](https://img.shields.io/badge/EXPLORE-GitPulse-5B3A8E?style=for-the-badge&logo=github)](https://github.com/Priyanka170974/GitPulse)

GitPulse focuses on transforming GitHub repository information into useful visual insights through a developer-friendly dashboard.

**Key areas**
- Repository analytics
- Programming language insights
- Contributor information
- Commit activity
- GitHub API integration
- JWT authentication
- MongoDB data management

### Architecture

```mermaid

    A[Developer] --> B[React + Vite]

    F --> G[(MongoDB)]
    D --> H[Repository Insights]
    H --> B
```
