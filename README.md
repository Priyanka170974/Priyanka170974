### `02. EVENTFLOW` — Registration & Smart Check-in

**An event management platform designed around digital tickets and attendee validation.**

```mermaid
flowchart TD
    A([Choose Event]) --> B[Submit Registration]
    B --> C{Request Valid?}
    C -- No --> X[Return Error]
    C -- Yes --> D{Duplicate?}
    D -- Yes --> X
    D -- No --> E{Capacity Available?}
    E -- No --> X
    E -- Yes --> F[(Store Registration)]
    F --> G[Generate Ticket and QR]
    G --> H[Present Ticket]
    H --> I[Scan QR or Enter ID]
    I --> J{Valid and Unused?}
    J -- No --> K[Reject Check-in]
    J -- Yes --> L[Record Check-in]
    L --> M[Refresh Event Stats]

    style A fill:#071426,stroke:#00D9FF,color:#FFFFFF
    style F fill:#071426,stroke:#00D9FF,color:#FFFFFF
    style G fill:#0B2D52,stroke:#00D9FF,color:#FFFFFF
    style L fill:#0B2D52,stroke:#00D9FF,color:#FFFFFF
    style M fill:#071426,stroke:#00D9FF,color:#FFFFFF
```

**Engineering highlights**
- Organizer and volunteer roles.
- Event creation and management.
- Registration capacity and duplicate checks.
- QR ticket generation and PDF support.
- Camera-based QR scanning and manual ticket lookup.
- Check-in validation and event statistics.

**Built with:** React · Vite · Node.js · Express.js · MongoDB · Mongoose · JWT
